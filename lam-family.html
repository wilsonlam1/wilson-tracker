📈 移動止蝕規則（Trailing Stop）
持倉升幅止蝕上移至原理
+10%買入點 +2%（保本）確保這筆交易不虧損
+20%買入點 +10%鎖定部分利潤
+30%買入點 +20%繼續讓利潤奔跑
每升5%距當前價 -8%持續移動，保護大部分利潤
🚫 嚴禁在 +5% 至 +15% 範圍內主動賣出！這是過去虧損的最大根源。
⚡ 加碼 & 禁止加碼規則
✅ 可以加碼的情況
股價突破後上升超過20%，成交量再放大，形成新VCP形態
加碼金額不超過原始倉位的50%
加碼後單倉不超過B桶8%上限
❌ 嚴禁加碼的情況
向下攤平（股價跌時買入）
市場評分低於5分時追加倉位
熔斷已觸發（-10%以上回撤）
同一行業已有兩隻持倉

☁️ 雲端同步 (GitHub Gist)
免費跨裝置同步。需要一個 GitHub 免費帳號，建立 Personal Access Token 即可。
設定步驟（只需一次）：
1. 登入 github.com → 右上角頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 點「Generate new token」→ 勾選 gist 權限 → 生成並複製 token
3. 貼入上方 Token 欄 → 點「建立雲端檔案」（只需一次，Gist ID 自動填入）
4. 電腦點「推送到雲端」存檔；手機打開此 HTML → 輸入相同 Token + Gist ID → 點「從雲端載入」
